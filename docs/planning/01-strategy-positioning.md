# 1. Strategy, Positioning & Authentic Voice
*(see `00-index.md` for `[STD-CTA]`, `[VOICE]`, `[RESPONSE-PROMISE]` shorthand)*

**Business Context**
- Founder: Trevor Lam — solo developer, self‑taught, no formal CS education.
- Workflow: AI‑augmented across full lifecycle (research, planning, coding, QA).
- Current state: launching with zero clients, no traditional portfolio. Monorepo houses firm site + client projects + demos.
- Primary launch asset: live demo websites on subdomains, substituting for case studies/logos.

**Positioning**
Core line: *"A solo, AI‑accelerated developer delivering high‑converting websites, marketing systems, and business apps — faster, more affordably, and with direct access to the person doing the work."*

Key messages: Speed (AI handles boilerplate, craft/logic stay human, ships in weeks) · Cost (no agency overhead, budget goes into the build) · Direct communication (no account managers) · Modern execution (Next.js/Tailwind, no templates) · Proof by demos (live clickable subdomains).

**Solving the "No Clients" Trust Gap** — four pillars:
1. **Live demos** (`/demos`) — multiple production‑grade subdomain projects, framed as self‑initiated but client‑standard.
2. **Process transparency** — phase‑by‑phase workflow replaces traditional portfolio reassurance.
3. **Authentic founder story** — About page states the self‑taught, AI‑augmented path plainly as an advantage; no fictional history.
4. **Behavioral proof** — `[RESPONSE-PROMISE]`.

**Target Audience**
SMBs needing new/redesigned site · startups/product owners needing high‑converting landing pages · local service businesses (restaurants, trades, professional services) with booking/contact needs · businesses needing lightweight custom web apps without a dev team. Common thread: value direct communication, predictable pricing, results without agency complexity.

**Conversion Strategy**
- Macro‑goal: contact form submission or Calendly booking.
- Micro‑goal: click‑through to a live demo subdomain (warms prospects).
- Funnel: Home (value prop + featured demo + CTAs) → Services (positions solo+AI, links to demos) → Demos (live proof, "Back to main site" link) → Process (removes uncertainty) → About (personal trust) → Contact (low‑friction form + Calendly).
- CTA language: `[STD-CTA]`.

**Guiding Copy Principles**
- Benefit‑driven — every sentence answers "what's in it for the client."
- Jargon‑free plain English.
- `[VOICE]` — firm name "YDM Agency," never we/us. Solo‑ness not revealed until trust earned (e.g. "You'll work with the person who builds your project").
- One primary CTA per page, visually dominant.
- Trust signals near conversion points: live demo links, response‑time promise, visible email, optional Calendly, no fake testimonials.

This section anchors all subsequent design/copy/technical decisions.
